# Sound library artwork

Background photographs for the Sounds tab cards, from Unsplash, bundled.
Same licence position as `assets/mixes/README.md`: free for commercial use,
no attribution required when downloaded and bundled (attribution is only
mandatory for images served live through the Unsplash API). No indemnification
on the free tier. None of these contain an identifiable person.

The colour noises are generated and have no literal subject, so they use
textures that suggest the sound's character rather than depict a source.
