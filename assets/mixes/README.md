# Mix card artwork

Four photographs used as dimmed backgrounds on the mix cards, from Unsplash.

Under the Unsplash License these are free to use commercially, including in a
shipped app, with no attribution required and no permission needed. Attribution
is only mandatory when images are pulled live through the Unsplash API — these
are downloaded and bundled, so that does not apply.

Two caveats worth keeping in mind, from Unsplash's own terms:

- The free tier carries no indemnification. If a photo were ever taken down or
  disputed, that risk sits with us.
- Images with recognisable people need a model release for commercial use, and
  Unsplash does not verify that releases exist. All four of these are landscape
  or object photographs with no identifiable person in them, chosen partly for
  that reason.

Each is 600px wide at quality 70, which covers the card at 3x. They are drawn
at low opacity behind a scrim, so detail matters far less than tone.
